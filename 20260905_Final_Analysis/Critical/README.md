# Critical lipidomics outputs

- 01_lipidomics_PCA_biological_samples: ordinary 485-feature PCA; PC1 48.6%, PC2 10.7%.
- 01_lipidomics_PCA_with_pooled_QC: PCA including pooled QC injections.
- 04_all_selected_features_heatmap: 60-feature heatmap.
- 05_selected_feature_PCA: PCA of the selected 60 features.
- 05_day_PLSDA: Day-supervised model; component 1 (48.6%) on X and
  component 2 (10.6%) on Y. Generated by Code 05.
- Original_PLSDA_day_horizontal_passage_vertical: requested passage-supervised
  model view; negative original component 2 (44.3%) on X, original component 1
  (8.2%) on Y. Generated by Code 06; PNG and SVG.
- 02_selected_consistent_direction_features.csv: selected features.
- 03_lipid_annotation_tables.xlsx: putative annotations and search evidence.

Day-model validation: ../Tables/05_day_PLSDA_* and
../Tables/05_multivariate_analysis_summary.csv.
Original passage-model validation: ../Tables/06_original_passage_PLSDA_*.
The two models share inputs but have different targets.

Exploratory PCA and ASCA examples are in ../Exploratory, with Codes 07-08.
