# Critical lipidomics outputs

- `01_lipidomics_PCA_biological_samples`: global PCA of 45 biological samples.
- `01_lipidomics_PCA_with_pooled_QC`: global PCA including 10 pooled-QC injections.
- `04_all_selected_features_heatmap`: main 60-feature heatmap with binary annotation status.
- `05_selected_feature_PCA`: PCA of the 60 selected features.
- `05_three_group_PLSDA`: three-group PLS-DA; validation statistics are reported in `05_multivariate_analysis_summary.csv`.
- `02_selected_consistent_direction_features.csv`: the 60 features selected in Code 02.
- `03_lipid_annotation_tables.xlsx`: feature-level annotations, all LIPID MAPS candidates, heatmap order and sources.
